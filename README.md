# Electricity Consumption Analysis

Streamlit dashboard for electricity demand forecasting, consumption analysis, data warehouse and OLAP.

## Download large files

These files are too big for GitHub. Download them and keep them in the same folder as app.py:

- [electricity_model.pkl](https://drive.google.com/file/d/1GvaSNcl_zypfQ4BNA-aGMnt09MnVxeIY/view?usp=sharing)
- [electricity_datawarehouse.db](https://drive.google.com/file/d/1P3AY_DPkvKzaFtx5HlM1SUeJMCT3dgnd/view?usp=sharing)
- [preprocessed_electricity_data.csv](https://drive.google.com/file/d/1rOrMQk1mqglMgnSTLwdYkLjaqyMSoKzl/view?usp=sharing)

## Run

```
pip install -r requirements.txt
streamlit run app.py
```
